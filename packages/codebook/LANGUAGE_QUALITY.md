# Language Quality Status

This file tracks the current review state for each public codebook language.
`CODEBOOK_GUIDE.md` remains the policy source of truth; this file is the
operational status board for follow-up passes.

Current automated gates cover all 180 target languages:

- distributed codebook presence, expected count, uniqueness, URL-safe
  single-token words, no exact English-codebook overlap, no generated
  language-prefix scaffolds, and no generated language-slug/English scaffolds;
- API support, runtime wordset counts/loaders, web locale mappings, message
  files, and place-type files;
- non-brand UI strings with no exact English fallback;
- place-type labels with no exact English fallback;
- Earth, Moon, and Mars region file presence;
- reviewed region-label samples plus a representative `region-3` ocean-label
  localization guard for every expanded language.

These gates prove the language set is structurally complete and fallback-free
for the checked surfaces. They do not replace native-speaker review; languages
remain `active cleanup` until a dedicated review pass finds no high-confidence
replacement candidates.

Review checklist:

1. Every public language must have a distributed codebook, earth region labels,
   moon labels, Mars labels, API support, web locale mapping, and production
   smoke coverage.
2. Every public codebook must keep its expected count, stay unique, avoid URL
   separators or whitespace, avoid mirroring the English codebook, and keep
   language-slug/English scaffold compounds out of the long tail.
3. Every reviewed UI and place-type file must stay free of scaffold markers,
   generated language prefixes, and disallowed exact English fallback.
4. Region-label changes must preserve reviewed multilingual samples and the
   expanded `region-3` representative ocean-label guard.
5. A language marked `active cleanup` can ship, but every new quality pass must
   add exact regression examples to the audit tests.
6. Do not raise a language to `stable` until the latest sub-agent review finds
   no high-confidence removal candidates.
