# Language Quality Status

This file tracks the current review state for each public codebook language.
`CODEBOOK_GUIDE.md` remains the policy source of truth; this file is the
operational status board for follow-up passes.

Current automated gates cover all 180 target languages:

- distributed codebook presence, expected count, uniqueness, URL-safe
  single-token words, no exact English-codebook overlap, no generated
  language-prefix scaffolds, and no generated language-slug/English scaffolds;
- API support, runtime wordset counts/loaders, web locale mappings, message
  files, and place-type files;
- non-brand UI strings with no exact English fallback;
- place-type labels with no exact English fallback;
- Earth, Moon, and Mars region file presence;
- reviewed region-label samples plus a representative `region-3` ocean-label
  localization guard for every expanded language.

These gates prove the language set is structurally complete and fallback-free
for the checked surfaces. They do not replace native-speaker review, but the current stable-grade gate
requires a dedicated automated review pass that finds no high-confidence
replacement candidates across the checked public surfaces.
