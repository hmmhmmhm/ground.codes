# French Codebook Dataset Notes

`bip39-normalized-seed.json` is a URL-normalized seed derived from the French
BIP39 word list distributed in `@ethersproject/wordlists@5.8.0` under the MIT
license. Entries were normalized to ASCII title case and filtered for length,
shape, duplicates, and obvious sensitive terms before being mixed with
project-curated French words and conservative generated compounds.
